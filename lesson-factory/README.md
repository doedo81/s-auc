# lesson-factory

초등 수업 자료(지도안 · 활동지 · 슬라이드) 제작 파이프라인.

> **현재 상태: P0 (계약 정의) 완료.** 아직 아무것도 자동으로 만들지 않는다.
> 스키마와 루브릭만 확정된 단계다.

---

## 왜 만드는가

수업 자료를 AI로 만들 때 반복되는 실패가 있다 — **활동지와 슬라이드가 지도안 없이 따로 만들어져
서로 맞는지 확인할 방법이 없는 것.** (실과 4단원에서 실제로 발생: *"지도안 파일 부재 →
성취기준 기반 재구성 → 원본 지도안과 대조 필요"*)

이 파이프라인은 **지도안을 유일한 진실로 고정**하고, 활동지·슬라이드가 거기서 파생되며,
일치 여부를 **기계가** 검사한다.

## 설계 원칙 4개

1. **에이전트는 LLM 호출 1회** — JSON 입력, JSON 출력. 모델이 다른 모델을 호출하지 않는다.
   위계는 코드의 상태기계가 만든다.
2. **기계로 검사 가능한 것은 LLM에게 묻지 않는다** — 실패하면 LLM 검수를 호출조차 하지 않는다.
3. **검수자는 제작자의 사고 과정을 보지 않는다** — 산출물과 루브릭만. (앵커링 방지)
4. **하드 제약은 프롬프트가 아니라 코드에.**

## "즐겁고 협동적이고 참여도 높게"를 어떻게 보장하는가

프롬프트로 부탁하지 않는다. **케이건 협동학습 구조 9종을 스키마 enum으로 강제**한다.

- 전개 활동은 9종 중 하나를 반드시 고른다 (스키마)
- 서로 다른 구조를 2종 이상 쓴다 (기계 검증, P2)
- 고른 구조가 요구하는 활동지 항목 역할을 전부 갖췄는지 검사한다 (기계 검증, P2)
  예: `생각-쓰기-짝-비교`는 `개인쓰기` 칸이 없으면 애초에 성립하지 않는다

## 교과서 대체 정책

**학습목표 도달이 유일한 기준이다.** 교과서 활동을 그대로 쓸 의무는 없고,
더 즐겁고 참여도 높은 활동으로 대체할 수 있다.

대신 교과서라는 안전망이 빠지므로 학습목표 연결을 조인다.

| 요구사항 | 강제 방법 |
|---|---|
| 모든 활동은 최소 1개 학습목표에 연결 | 스키마 (`objective_ids` minItems 1) |
| 모든 학습목표는 최소 1개 활동이 다룸 | 기계 검증 (역방향, P2) |
| 대체 시 `replaces` · `rationale` 필수 | 스키마 (if/then) |
| 대체가 원래만큼 목표에 도달시키는가 | LLM 검수 R6 |

## 디렉터리

```
contracts/     계약 — 이 프로젝트의 심장
  lesson_plan.schema.json    지도안 (유일한 진실)
  worksheet.schema.json      활동지
  slide_deck.schema.json     슬라이드
  verdict.schema.json        검수 결과
  kagan_structures.json      케이건 9종 + 항목 역할 요구사항
  era_palettes.json          시대별 팔레트 (제작 지침 v3)
  rubric.md                  LLM 검수 루브릭 R1~R7
tests/         계약 검증 (LLM 호출 없음)
CLAUDE.md      프로젝트 규칙 헌법 — 모든 AI 작업자 필독
```

`core/` `agents/` `checks/` `render/` `bot/` 는 P2 이후에 채운다.

## 지금 할 수 있는 것

```bash
cd lesson-factory
pip install -r requirements.txt
python3 -m pytest tests/ -q        # 27개 통과 — LLM 호출 0회, 비용 0원
```

테스트가 확인하는 것:

- 스키마 4종이 유효한 JSON Schema인가
- 정상 픽스처(사회 5-2 2단원 1차시)가 통과하는가
- **불량 픽스처가 실제로 걸리는가** — 학습목표 없는 활동, 케이건 구조 없는 전개,
  근거 없는 대체, 정답 슬라이드의 출처 누락, OX 4문제 아님, 수정안 없는 불합격 판정 등
- **계약 파일들끼리 어긋나지 않는가** — 스키마의 케이건 enum ↔ `kagan_structures.json`,
  구조가 요구하는 역할 ↔ 활동지 role enum, era enum ↔ 팔레트 파일

> 마지막 항목이 중요하다. 계약 파일이 3개로 갈라져 있으면 하나만 고치고 나머지를 잊는다.
> 그러면 지도안은 통과하는데 활동지 템플릿이 없는 사태가 난다.
