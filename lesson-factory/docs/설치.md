# 내 컴퓨터에 설치하기 (윈도우)

한 번만 하면 된다. 다 하면 **명령 한 줄로 세안·활동지가 드라이브 폴더에 떨어진다.**

막히면 [진단](#진단이-먼저다)을 먼저 돌린다 — 지금 뭐가 없는지 알려 준다.

---

## 0. 필요한 것

| | 왜 | 확인 |
|---|---|---|
| **파이썬 3.11 이상** | 파이프라인이 파이썬이다 | `python --version` |
| **Git** | 저장소를 받아 오려고 | `git --version` |
| **Claude Code** | 세안을 쓰는 엔진. **구독으로 돌아간다** | `claude --version` |

**API 키는 필요 없다.** 키는 종량제 별도 청구고, 구독(Pro/Max)과 지갑이 다르다.
Claude Code 를 이미 쓰고 있다면 그것으로 돈다.

파이썬을 새로 깐다면 설치 화면에서 **"Add Python to PATH"** 를 반드시 켠다.
안 켜면 `python` 명령을 못 찾는다.

## 1. 저장소 받기

PowerShell 을 열고 (시작 → `powershell`):

```powershell

cd s-auc
```

> `claude/elementary-lesson-automation-nv889q` 가지에 있다.

전자는 API 키로 돌릴 때만, 후자는 아직 안 만든 슬라이드 렌더러용이다.

611개가 들어간다. **이게 없으면 아무것도 못 만든다** — 성취기준을 지어내지 못하게
DB 조회로만 쓰기 때문이다(`CLAUDE.md` B-1). 여러 번 돌려도 결과는 같다.

## 4. 산출물이 떨어질 곳 정하기

`.env.example` 을 복사해 `.env` 로 만들고, 한 줄만 채운다.

```powershell
copy .env.example .env
notepad .env
```

```
LESSON_OUT=G:\내 드라이브\도학원\교육자료_통합보관소\2026학년도\5학년\2학기
```

그러면 이렇게 쌓인다.

```
G:\내 드라이브\...\5학년\2학기\
├── 사회\사회-5-2-3_14차시\   ← 세안 · 활동지(학생용) · 활동지(교사용)
├── 과학\
└── 실과\
```

`G:` 는 구글 드라이브 데스크톱이 물린 자리라 **동기화는 드라이브가 알아서** 한다.
비워 두면 저장소 안 `artifacts\` 에 쌓인다(깃에 올라가지 않는다).

> `.env` 는 깃에 안 올라간다. 비밀과 개인 경로가 들어가는 자리다.

## 돌리기

```powershell
python run.py 사회 5 2 3/14 --standards 6사05-01              # 미리보기
python run.py 사회 5 2 3/14 --standards 6사05-01 --write       # 저장
```

- `3/14` — 3차시(총 14차시). 교과서 등록부를 찾는 열쇠다
- `--standards` — 성취기준. DB 에 없는 코드를 주면 **멈춘다**(지어내지 않는다)
- **`--write` 없이는 파일이 생기지 않는다.** 먼저 미리보기로 확인하라는 뜻이다

이미 만든 JSON 에서 문서만 다시 뽑을 수도 있다.

```powershell
python -m render.sean_docx tests\fixtures\사회-5-2-2단원-2차시.plan.json --write
python -m render.worksheet_docx tests\fixtures\사회-5-2-2단원-2차시.worksheet.json --write
```

## 수업 자료 넣기 (품질이 여기서 갈린다)

없어도 돌아가지만, **약안과 교과서를 넣으면 결과가 확 달라진다.**
넣지 않으면 모델이 등록부의 학습목표만 보고 활동을 스스로 짜야 한다.

```
materials\inbox\사회\
├── 약안\2단원_2-1_유교조선.md          ← 소단원 약안 한 개
├── 교과서\사회-5-2-080.txt             ← 쪽마다 한 장. 080 처럼 세 자리
└── 지도서\사회-5-2-176.txt
```

**쪽별로 쪼개는 이유**: 차시가 쓰는 쪽만 골라 보내기 위해서다. 소단원 전체를 한
파일로 넣으면 3차시를 만들 때 7차시 내용까지 딸려 가서, 모델이 다음 차시 내용을
미리 끌어다 쓴다.

`materials\inbox\` 는 깃에 올라가지 않는다 — 교과서 본문이 들어가는 자리라
공개 저장소에 올리지 않는다(`CLAUDE.md` A-1·A-3).

## 진단이 먼저다

무엇이 안 되든 이것부터 돌린다. **없는 것마다 고치는 명령을 같이 인쇄한다.**

```powershell
python scripts\doctor.py
```

| 증상 | 원인 |
|---|---|
| `python` 을 찾을 수 없다 | 설치할 때 'Add Python to PATH' 를 안 켰다. 다시 설치하거나 PATH 에 추가 |
| `성취기준 DB 없다` | 3번을 안 했다 |
| `산출물 위치 — 그런 폴더가 없다` | 구글 드라이브 데스크톱이 꺼져 있으면 `G:` 가 안 보인다 |
| `생성 엔진 없음` | Claude Code 가 없다. `npm install -g @anthropic-ai/claude-code` |
| 세안은 나오는데 교과서 내용이 없다 | `materials\inbox\` 가 비어 있다 (위 참조) |
