## 검사가 한 번 뚫렸다가 막힌 곳

`verified: true` 가드가 `source` 에 '교과서'가 들어 있는지만 봤다. 쪽수를 교과서로 확인하고
모든 차시 `source` 뒤에 `· 쪽수는 교과서에서 확인` 을 붙였더니 **통과해 버렸다.**
출처의 **첫머리**로 판정하도록 고쳤다. (`test_verified_requires_textbook_source`)

## 렌더러를 만들자 스키마 구멍이 하나 드러났다 (2026-07-29)

활동지를 종이로 뽑으려니 `answer_space: "표"` 만으로는 **몇 칸짜리 표인지 알 수 없었다.**
검사만 돌릴 때는 문제가 없었다 — 검사는 칸의 모양을 묻지 않기 때문이다.
`columns`(열 머리) · `rows` · `row_labels`(첫 칸 미리 인쇄) 를 넣었다.

그러면서 **정답이 샐 자리가 하나 늘었다.** 표 첫 칸에 건물 이름을 박아 두는 것은
옮겨 적는 시간을 줄이는 좋은 일이지만, 같은 자리에 덕목을 박으면 활동이 통째로 사라진다.
`_printed_item_text()` 를 만들어 발문·열 머리·첫 칸을 모두 정답 검사 대상에 넣었고,
게임 정답은 `·` 로 쪼개 **조각 단위로** 대조하게 했다 — 새는 쪽은 언제나 한 조각이다.
(`test_answer_in_row_labels_is_detected`)

교훈: **산출물을 실제로 뽑아 보기 전에는 계약이 완성됐는지 알 수 없다.**
검사를 통과한다는 것과 종이로 나온다는 것은 다른 일이었다.

## 구독제로 돌린다 — API 키를 쓰지 않는다 (2026-07-29)

담임 질문: *"난 정액제인데 API 키를 꼭 써야 돼?"* **아니다.**

**API 키는 종량제 별도 청구**다. 구독(Claude Pro/Max)과 지갑이 다르고, 키를 만들면
쓴 만큼 따로 결제된다. 구독은 **Claude Code 사용**을 덮고, Claude Code 에는 비대화형
모드(`claude -p`)가 있다. 그래서 `core/llm.py` 에 `ClaudeCodeClient` 를 붙였다 —
`--output-format json` 으로 부르고 결과 JSON 만 꺼내 온다.

보내는 모양은 API 경로와 **같게** 맞췄다. 시스템 자리에 프롬프트
(`--append-system-prompt`), 사용자 자리에 입력 JSON(stdin). 모양이 갈리면 나중에
API 로 옮길 때 결과가 달라지고, 그러면 지금 검증한 프롬프트 품질이 보증되지 않는다.

`run.py --backend auto` (기본값): 키가 있으면 API, 없으면 Claude Code.

### 알고 써야 하는 차이 두 가지

| | 내용 |
|---|---|
| **군더더기 토큰** | Claude Code 자체 시스템 프롬프트가 매 호출에 **2만 7천 토큰**쯤 실린다(실측). 돈이 아니라 사용량으로 나간다 |
| **`total_cost_usd` 는 청구액이 아니다** | 구독제면 실제로 빠져나가는 돈이 아니라 환산액이다. 이 값으로 상한을 걸면 있지도 않은 돈을 세게 되므로, 보고에 `환산액(구독제면 실제 청구 아님)` 이라고 붙여 인쇄한다 |

비용은 **CLI 가 계산해 준 값을 그대로** 적는다. 우리 단가표로 다시 계산하면 캐시
토큰을 빼먹어서 실제와 어긋난다 — 어긋난 숫자를 남기느니 CLI 것을 믿는다.

### 첫 실호출에서 잡은 것 — 도구를 꺼야 한다

구독 경로로 2차시를 실제로 생성해 봤더니 **출력 41,063 · 캐시 쓰기 125,937 토큰**이
나왔다. `claude -p` 는 기본적으로 **도구를 들고 에이전트 루프로 돈다** — 모델이 저장소
파일을 읽으며 여러 턴을 돈 것이다.

토큰도 토큰이지만 이게 **C-3 위반**이다. 에이전트는 LLM 호출 1회여야 하고, 자료를
읽는 것은 코드의 일이다. 도구를 열어 두면 모델이 우리가 조립해 준 입력(등록부·DB·
inbox)을 건너뛰고 저장소를 직접 뒤지게 되어, **입력을 고정한 의미가 사라진다.**
B-1(성취기준은 DB 조회로만)도 같이 무너진다.

`--tools "" --strict-mcp-config` 을 붙여 막았다. 실측으로 캐시 쓰기가
**27,319 → 2,961** 로 떨어지고 1턴에 끝난다. (`test_claude_code_turns_every_tool_off`)

교훈: **배관은 돌아간다고 다 된 게 아니다.** 검사를 통과한 산출물이 나왔지만
만들어진 방식이 규칙을 어기고 있었고, 그건 토큰 수를 들여다보고서야 보였다.
