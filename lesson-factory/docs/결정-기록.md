# 담임 결정 기록

파이프라인의 규칙이 바뀐 지점만 남긴다. **"왜 그렇게 되어 있는가"** 를 나중에 되짚기 위한 문서다.

## 2026-07-28

| 결정 | 반영 |
|---|---|
| 런타임 Python · 승인은 텔레그램 · 첫 대상 사회 5-2 | 아키텍처 |
| 산출물은 지도안 + 활동지 + 슬라이드 (게임 제외) | 스키마 3종 |

| 시대별 팔레트 5종 확정 | `era_palettes.json` |

## 정정한 것

내가 틀렸고 선생님이 바로잡은 것들. 같은 실수를 반복하지 않으려고 남긴다.

| 내가 한 말 | 사실 |
|---|---|
| 「게임형협동수업 완성본」은 사회 5-2 자료다 | **실과**다. 사회 5-2 게임은 2개뿐 |
| 성취기준 `6사03-02` 는 존재하지 않는다 | **존재한다**(인권). 다만 조선 후기 수업엔 안 맞는다 — DB 검사의 한계 사례로 테스트에 남김 |
| 세안은 활동지를 쓰지 않는다 | **쓴다.** 활동지 PDF를 못 찾은 상태에서 내린 판단이었다 |
| 케이건 학습지 템플릿 9종 `.docx` 가 있다 | **없다.** 실물은 `00_협동학습_구조_사용법.pdf`(학생용 구조 카드 10종) |
