# lesson-factory 프로젝트 규칙 (모든 AI 필독)

이 문서는 이 프로젝트에서 일하는 모든 AI 작업자가 작업 시작 전 반드시 읽는 헌법이다.
사람이 정한 것이며, AI가 임의로 고치지 않는다.

---

## A. 저작권 · 자료 출처 (최우선)

1. **교과서 본문·사진은 저작권법 제25조(학교교육 목적 이용)에 따라 우리 반 수업용으로만 사용한다.**
   모든 산출물 푸터에 `신리초 5-5 수업용 · 외부 배포 금지` 를 자동 삽입한다.
2. 외부 자료(인디스쿨 등)는 **사람이 직접 내려받아 `materials/inbox/`에 넣은 파일만** 참조한다.
   자동 로그인·자동 크롤링·자동 다운로드를 구현하지 않는다.
3. 산출물을 공개 저장소·공개 URL에 올리지 않는다. `artifacts/`는 `.gitignore` 대상이다.

## B. 코드 절대 규칙 (위반 금지)

1. **성취기준은 `curriculum/standards.sqlite` 조회로만 사용한다.**
   조회에 실패하면 작업을 실패 처리한다. 성취기준 코드나 문구를 모델이 지어내는 것을 금지한다.
2. **파일 쓰기는 `dry_run=True`가 기본값이다.** 실제 저장은 `--write`를 명시했을 때만 일어난다.
3. API 키는 하드코딩 금지 — 반드시 `.env` 환경변수.
4. 모든 LLM 호출의 모델·토큰·비용을 `llm_calls` 테이블에 기록한다.
   작업(trace_id)당 비용 상한을 넘으면 중단하고 사람에게 알린다.
5. 산출물은 **DB + 파일 이중 기록**한다.
6. 재작업(revision)은 **최대 2회**. 초과하면 `ESCALATED`로 두고 사람을 호출한다.

## C. 아키텍처 원칙

1. **기계로 검사 가능한 것은 LLM에게 묻지 않는다.**
   `checks/`가 먼저 돌고, 실패하면 LLM 검수를 호출하지 않는다.
2. **검수자는 제작자의 사고 과정을 받지 않는다.**
   검수 입력은 산출물 + 루브릭뿐. 이전 재작업 이력과 교사 에이전트의 추론을 넘기지 않는다. (앵커링 방지)
3. **에이전트는 LLM 호출 1회**다. JSON 입력 → JSON 출력. 모델이 다른 모델을 호출하지 않는다.
4. **모듈 간 통신은 SQLite 상태기계**로 한다. 메시지에는 본문 대신 `payload_ref`(파일 경로)만 싣는다.
5. **침묵 금지** — 아무 일이 없어도 하루 한 통은 보낸다. 그래야 "메시지 없음 = 고장"이 성립한다.

## D. 수업 내용 원칙

1. **학습목표 도달이 유일한 기준이다.** 교과서 활동을 그대로 쓸 의무는 없다.
   더 즐겁고 참여도 높은 활동으로 대체할 수 있다.
2. 다만 대체할 때는 `source="대체"`, `replaces`, `rationale`을 반드시 채운다.
   교과서라는 안전망을 뺀 만큼 **학습목표 연결을 기계가 양방향으로 검사**한다.
3. `meta.textbook_pages`는 대체하더라도 남긴다. 진도표·평가 근거로 필요하다.
3-1. **학습목표는 교과서·지도서를 따른다.** `curriculum/textbook/<과목>-<학년>-<학기>.json` 이 유일한 출처다.
   **학습목표를 찾을 때는 지도서를 먼저 본다** (담임 지적, 2026-07-29 *"학습목표를 찾으려면 지도안을
   찾으면 되잖아. 지도서 PDF도 있으니까 그거 참고해"*). 실제로 순서가 이렇다.
   1. **지도서 각론의 차시별 「학습 목표」** — `구석기 시대 사람들의 생활 모습을 설명할 수 있다.` 형태.
      가장 정확하다.
   2. **지도서 앞부속 「연간 지도 계획」** — 48차시 전부의 차시명과 교과서 쪽수가 한 표에 있다.
   3. **교과서 소단원 첫 쪽 「이 주제를 공부하면」** — 소단원 목표. 차시별이 아니다.
   4. 선생님 학습지·약안 — 위가 다 막혔을 때만. 이때는 `verified: false`.
   담임 요구(2026-07-29): *"교과서 학습목표 일치시키고. 지금은 사회 교과서만 있는데 계속 보충해줄게."*
   - **등록되지 않은 과목·차시는 경고만 내고 지나간다.** 없는 것을 실패로 만들면 다른 과목을
     시작할 수 없고, 그러면 등록부를 지어내서 채우게 된다 — B-1 이 막으려던 바로 그 일이다.
   - `verified: true`(교과서 원본 대조 완료)와 어긋나면 **실패**. `false`면 경고.
   - `verified: true` 로 표시하려면 `source` 가 교과서·지도서여야 한다. 선생님 자료를 보고
     '확인함'이라 적는 것은 확인이 아니다 (스키마가 막는다).
4. 전개 활동은 **케이건 협동학습 구조를 반드시** 사용한다. 목록의 유일한 출처는
   `contracts/kagan_structures.json` 이며, 개수를 여기에 적어 두지 않는다(실물 조사로 늘어난다).
   `worksheet_verifiable=true` 인 구조만 활동지 역할까지 기계 검증된다.
   (2026-07-29 확인: 구조별 학습지 템플릿 `.docx` 는 존재하지 않는다. 실물은
   `00_협동학습_구조_사용법.pdf` — 학생이 읽는 구조 카드 10종이며 `card` 필드에 있다.)
5. 슬라이드는 문제·정답 분리, 발문·시간은 발표자 노트에만, 시대별 팔레트를 지킨다.
   **고정 순서는 강제하지 않는다** — 실물 덱이 차시마다 다른 서사를 따르는 것을 확인했다(2026-07-28).
6. **인쇄량 (담임 요구, 2026-07-29).**
   - **개인 배부 활동지는 1면, 많아야 2면(양면 한 장).** 학생 한 명당 종이 한 장이 상한이다.
   - **넘으면 막지 말고 담임에게 보여 준다** (`severity="review"`). 자를 곳을 정하는 것은
     수업을 아는 사람의 판단이고, 기계가 임의로 자르면 학습에 필요한 칸이 날아간다.
   - **모둠 배부는 분량 제한이 없다.** 우리 반은 **6개 모둠**이고, 모둠마다 다른 것을 줘도 된다.
7. **활동지는 템플릿을 채우는 것이 아니라 차시마다 새로 짠다.** (제작 규칙 §3-7:
   *"레이아웃은 내용에 맞게 유연하게 — 2×2로 획일화하지 말 것"*) 다만 **골격은 매 차시 같다** —
   🎯학습 목표(맨 위) · 📖교과서 쪽 · 협동학습 구조 · 사회적 기술 · 💡느린 힌트 · ⭐빠른 보너스 ·
   📝마무리(한 문장 + OX 4문제). **활동지에 정답을 인쇄하지 않는다** — 정답은 교사용에만.
8. **지도안은 세안으로만 쓴다.** 담임 결정(2026-07-29): *"약안 말고 세안으로 짜줘. 약안은 게임 내용을
   모르겠더라."* 활동마다 T/S 발화(`blocks`)를 채우고, 게임이 있으면 `game` 블록에 절차·단서·문장틀까지
   적는다. **게임 명세만 따로 읽어도 교실에서 굴러가야 한다.** 게임 HTML 은 만들지 않는다.
   **약안은 산출물이 아니라 입력이다** — 기존 약안 md 7개는 내용 공급원으로 읽기만 하고,
   파이프라인이 약안을 새로 만들지 않는다.

## E. 코드 컨벤션

- Python 3.11+, type hints, docstring(한글 가능)
- 외부 API 호출은 재시도 + 타임아웃 필수
- `checks/`의 모든 검사는 LLM 없이 동작해야 하며, 각 검사마다
  **통과 픽스처와 실패 픽스처를 함께** 테스트한다 (통과만 하는 검사는 검사가 아니다)
- 파일명 규칙: `[과목]-[단원]-[차시]-[유형]-v[n]` (예: `사회-5-2-2단원-1차시-활동지-v1`)

## F. 기본 모델

- 계획 수립(교사) · 검수 = `claude-opus-5`, `effort: "high"`
- 활동지·슬라이드 변환(보조강사) = `claude-opus-5`, `effort: "low"`
- 모델을 낮추기 전에 `effort`부터 조정한다.
