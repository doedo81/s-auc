# materials/

`inbox/` 는 **사람이 직접 넣은 파일만** 들어가는 자리다 (CLAUDE.md A-2).
자동 로그인·크롤링·다운로드는 구현하지 않는다. `core/materials.py` 에 네트워크
호출이 한 줄도 없는 것이 그 규칙의 이행이다.

`inbox/` 는 `.gitignore` 대상이다 — 교과서 본문이 들어가므로 저장소에 올리지 않는다.

## 어디에 무엇을 넣는가

```
materials/inbox/<과목>/
├── 약안/2단원_2-1_유교조선.md            ← 소단원 약안 (내용 공급원)
├── 교과서/사회-5-2-076.txt               ← 쪽마다 한 장. 076 처럼 세 자리
└── 지도서/사회-5-2-168.txt
```

쪽별로 쪼개 두는 이유는 차시가 쓰는 쪽만 골라 보내기 위해서다. 소단원 전체를 한
파일로 넣으면 2차시를 만들 때 7차시 내용까지 프롬프트에 실려, 모델이 다음 차시
내용을 미리 끌어다 쓴다.

## 없어도 돌아간다

파일이 없으면 **없다고 보고하고 그대로 진행한다.** `run.py` 가 「📭 없는 자료」로
찍어 주고, 프롬프트는 교과서가 `null` 이면 *"교과서 활동을 추측하지 말고 source 를
'대체' 로 두어라"* 로 받는다. 빈 자리를 지어내 채우는 것이 B-1 이 막으려던 일이다.
