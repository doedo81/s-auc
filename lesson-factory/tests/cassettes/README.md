# 녹음본 (cassettes)

`--offline` 로 돌릴 때 LLM 대신 읽는 JSON 이다. **LLM 호출 0회로 배관 전체를
시험하기 위한 것**이며, 수업 자료가 아니다.

파일명은 `<trace_id>.<agent>.json`. `core/llm.py` 의 `Client._replay` 가 찾는다.

지금 들어 있는 것은 2차시 세안 픽스처를 그대로 옮긴 것이다. 담임 판정을 통과한
산출물이므로 "검사를 통과하는 정상 입력" 으로 쓰기에 맞다. 실제 모델 출력이 아니라는
점은 분명히 해 둔다 — 이걸로 프롬프트 품질을 판단할 수는 없다.
